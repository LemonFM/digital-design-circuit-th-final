T Flip-Flop

2สร้าง T flip-flop จาก JK และ D สไลด์ 23 (Figure 11-24), 27 (d)

(a) จาก JK: ต่อ J = K = T

  • T = 0 ได้ JK = 00 จึง Hold
  • T = 1 ได้ JK = 11 จึง Toggle

JQ′ + K′Q = TQ′ + T′Q ✓

(b) จาก D: ต่อ D = T ⊕ Q

  • ใช้เกต XOR 1 ตัว input เป็น T และ Q ที่ป้อนกลับมา
  • D flip-flop ได้ Q⁺ = D = T ⊕ Q

Q⁺ = D = T ⊕ Q ✓

4ตัวหารความถี่ (T = 1 ตลอด) ต่อยอดสไลด์ 31: Counters

ถ้าตรึง T = 1 ไว้ Q จะกลับค่าทุกขอบขาลง จึงได้ 1 รอบของ Q = 2 รอบของ clock ความถี่ของ Q เท่ากับ ครึ่งหนึ่ง ของ clock ถ้าต่อหลายตัวเป็นทอด ๆ จะหารด้วย 2, 4, 8, … ซึ่งก็คือพื้นฐานของ counter

Q₂ คือ T flip-flop ตัวที่ 2 (T = 1) ที่ใช้ Q ของตัวแรกเป็น clock

5ลองกดวงจร

ตั้ง T = 1 แล้วกด "ส่ง clock 1 ลูก" หลาย ๆ ครั้ง Q จะสลับทุกลูก ถ้าตั้ง T = 0 Q จะคงที่ (ตัวนี้ทริกขอบขาลง ตามสไลด์)

จุดที่พลาดบ่อย
  • T = 1 คือ "กลับค่าจาก Q ปัจจุบัน" ไม่ใช่ "Q = 1"
