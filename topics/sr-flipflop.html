SR Latch & SR Flip-Flop

1Latch vs Flip-flop สไลด์ 1, 3

Latch และ flip-flop เป็นวงจร sequential ที่เก็บข้อมูลได้ 1 บิต output ขึ้นกับ input ปัจจุบัน และสถานะเดิม (Q) ต่างจากวงจร combinational ที่ดูแค่ input

Latch (level-sensitive)

ตลอดช่วงที่สัญญาณ enable ทำงาน สถานะจะเปลี่ยนตาม input ทันที และเมื่อปิด enable ก็จะจำสถานะไว้

Flip-flop (edge-triggered)

เปลี่ยนสถานะเฉพาะที่ ขอบที่ทำงาน (active edge) ของสัญญาณ clock คือขอบขาขึ้นหรือขอบขาลง พ้นขอบไปแล้วจะคงค่าไว้ไม่ว่า input จะเปลี่ยนอย่างไร

สัญลักษณ์ที่ใช้ในหน้านี้ (ตามสไลด์)
  • Q′ = นิเสธของ Q (บางตำราเขียน Q)
  • Q = สถานะปัจจุบัน · Qnext = สถานะถัดไป (ตำราอื่นเขียน Q⁺ หรือ Q(t+1))
  • S′, R′ = input แบบ active-low (ใส่ 0 เพื่อสั่งงาน) · E = Enable · × = don't care
  • RS flip-flop กับ SR flip-flop คือตัวเดียวกัน แค่เรียกต่างกัน

2Bistable element สไลด์ 2

ถ้าต่อ output ของ inverter กลับเข้า input ของตัวเอง ค่าจะขัดกันเอง จึงใช้ inverter 2 ตัวต่อเป็นวง แทน ได้วงจรความจำที่ง่ายที่สุด เพราะมี สถานะเสถียร 2 แบบ คือ Q = 0 หรือ Q = 1 แล้วค่าจะค้างอยู่อย่างนั้นด้วยวงป้อนกลับ

ข้อจำกัด วงจรนี้ไม่มี input จึงเปลี่ยนค่าที่เก็บไว้ไม่ได้ ต้องเปลี่ยน inverter เป็นเกต NOR หรือ NAND เพื่อเพิ่มขา S และ R และนี่คือที่มาของ SR latch

3SR latch แบบ NOR สไลด์ 4–5

ใช้เกต NOR 2 ตัว input เป็นแบบ active-high: S = 1 ทำให้ Set (Q = 1), R = 1 ทำให้ Reset (Q = 0), S = R = 0 ทำให้ Hold (จำค่าเดิม)

ทำไมได้ผลแบบนี้: NOR ให้ 0 ทันทีถ้ามี input ตัวใดเป็น 1

  • S = 1 ทำให้ Q′ = 0 แล้วเกตบนได้ NOR(0, 0) = 1 จึงได้ Q = 1
  • R = 1 ทำให้ Q = 0 แล้วเกตล่างได้ NOR(0, 0) = 1 จึงได้ Q′ = 1
  • S = R = 1 บังคับให้ ทั้ง Q และ Q′ เป็น 0
ทำไม S = R = 1 ถึงห้ามใช้ ได้ Q = Q′ = 0 ซึ่งขัดกับนิยามที่สองตัวต้องตรงข้ามกัน และถ้าปล่อย S, R กลับเป็น 0 พร้อมกัน เกตทั้งสองจะแข่งกันเปลี่ยน (race condition) ผลจึงเป็น Undefined บอกไม่ได้ว่า Q จะออกมาเป็น 0 หรือ 1

4S′R′ latch แบบ NAND สไลด์ 6

ใช้เกต NAND 2 ตัว input ชื่อ S′ และ R′ เป็นแบบ active-low: S′ = 0 ทำให้ Set, R′ = 0 ทำให้ Reset, S′ = R′ = 1 ทำให้ Hold

ทำไมได้ผลแบบนี้: NAND ให้ 1 ทันทีถ้ามี input ตัวใดเป็น 0

  • S′ = 0 บังคับให้ Q = 1 (Set)
  • R′ = 0 บังคับให้ Q′ = 1 จึงได้ Q = 0 (Reset)
  • S′ = R′ = 0 บังคับให้ ทั้ง Q และ Q′ เป็น 1
เทคนิคจำ ตาราง NAND คือตาราง NOR ที่กลับค่า input ทุกตัว ส่วนสถานะห้ามใช้ ถ้าเป็น NOR จะได้ Q, Q′ = 0, 0 ถ้าเป็น NAND จะได้ 1, 1 ในสไลด์ 6 ช่วง t4–t5 จะเห็น Q และ Q′ เป็น 1 พร้อมกัน และหลัง t6 กลายเป็น Undefined (ลองทำใน แบบฝึกข้อ 3)

5SR latch with Enable สไลด์ 7

เพิ่มเกต NAND 2 ตัวหน้า S′R′ latch และเพิ่มขา E (Enable) เพื่อคุมว่าเมื่อไรจะยอมรับ S, R

  • E = 0: ไม่สนใจ S, R เลย latch คงค่าเดิมไว้
  • E = 1: ทำงานเหมือน SR latch ปกติ input เป็นแบบ active-high (เกต NAND ด้านหน้ากลับค่าให้ จึงได้ S′ = (S·E)′ และ R′ = (R·E)′)

State diagram

มี 2 สถานะ คือ Q = 0 และ Q = 1 ลูกศรบอกว่าค่า SR แบบไหนทำให้ย้ายสถานะ หรืออยู่ที่เดิม

9Clock และ SR Flip-Flop สไลด์ 11–12, 18–19

Latch ยอมให้สถานะเปลี่ยนได้ตลอดเวลาที่เปิด enable แต่วงจรคอมพิวเตอร์ต้องการให้ทุกอย่าง เปลี่ยนพร้อมกันเป็นจังหวะ จึงใช้สัญญาณ clock (คลื่นสี่เหลี่ยม) คู่กับ flip-flop

Rising edge
0 → 1

ขอบขาขึ้น นิยมใช้เป็นขอบที่ทำงาน (active edge)

Falling edge
1 → 0

ขอบขาลง สัญลักษณ์มีวงกลมหน้าขา Clk

Clock cycle
ขอบขาขึ้น → ขอบขาขึ้นถัดไป

คาบ T = 1 / f เช่น f = 2 GHz ได้ T = 0.5 ns

ชนิดของ clocked flip-flop (สไลด์ 12)

ชนิดทำงานเมื่อหมายเหตุ
Level-triggeredระดับ high หรือ low ของ clockแม่นยำน้อยกว่า (ก็คือ latch with enable)
Edge-triggeredขอบขาขึ้นหรือขอบขาลงเท่านั้นจังหวะแม่นยำกว่า
Master–Slaveใช้ latch 2 ตัวทำงานสลับจังหวะกันoutput เปลี่ยนเฉพาะตอน clock เปลี่ยน แต่ latch ตัวหน้ารับ input ตลอดครึ่งคาบ (pulse-triggered)
ข้อความในสไลด์ 12 ที่ควรอ่านอย่างระวัง ตรวจทานเพิ่ม
  • สไลด์เรียกว่า "level-triggered flip-flop" แต่ตามนิยามทั่วไป อุปกรณ์ที่ทำงานตามระดับคือ latch ส่วน flip-flop หมายถึงแบบที่ทำงานตามขอบ
  • สไลด์บอกว่า "master clocked on the rising edge, slave on the falling edge" ที่ถูกคือ latch ทั้งสองตัวทำงานตาม ระดับ สลับกัน (เช่นในสไลด์ 14 และ 19 master เปิดตอน CLK = 0 และ slave เปิดตอน CLK = 1) ทำให้ output เปลี่ยนที่ขอบขาขึ้น

Master–Slave SR Flip-Flop (สไลด์ 19)

  1. CLK = 0: master เปิด จึงรับ S, R เก็บไว้ที่ P ส่วน slave ปิด Q จึงไม่เปลี่ยน
  2. CLK ขึ้นเป็น 1: master ปิด (จำค่า P ไว้) แล้ว slave เปิดและคัดลอก P ไปเป็น Q
  3. ผล: Q (output) เปลี่ยนเฉพาะที่ ขอบขาขึ้น เท่านั้น
ข้อควรระวัง: master–slave SR เป็น pulse-triggered ไม่ใช่ edge-triggered แท้ ตรวจทานเพิ่ม Q เปลี่ยนที่ขอบก็จริง แต่ค่าที่ได้ขึ้นกับ S, R ตลอดช่วง CLK = 0 ไม่ใช่แค่ค่า ณ ขอบ เช่น ถ้า S เป็น 1 แป๊บเดียวตอน CLK = 0 แล้วกลับเป็น 0 master จะถูก set ค้างไว้ (SR = 00 คือ hold) พอถึงขอบขาขึ้น Q ก็เป็น 1 ทั้งที่ ณ ขอบ S = 0 ถ้าโจทย์บอกว่าเป็น edge-triggered (เช่นแบบฝึกข้อ 4) ให้ดูค่า S, R เฉพาะ ณ ขอบ

10แบบฝึก timing diagram

ไล่ทีละช่วงเวลา ดูว่า input ช่วงนั้นเป็นคำสั่งอะไร (set / reset / hold) แล้วจึงหาค่า Q ข้อ 1–2 ให้ เริ่มต้น Q = 0 และไม่คิด propagation delay

ข้อ 1 · SR latch แบบ NOR หาค่า Q

เฉลยข้อ 1 t1–t2 set → 1, t3 hold → 1, t4 reset → 0, t6 set → 1, t8 reset → 0 ช่วงที่ S = R = 0 ให้ใช้ค่าเดิมของช่วงก่อนหน้า

ข้อ 2 · SR latch with Enable หาค่า Q (ระวังช่วง E = 0)

เฉลยข้อ 2 ที่ t0, t2, t4, t6, t8 มี S หรือ R เป็น 1 แต่ E = 0 จึงไม่มีผล Q เปลี่ยนแค่ที่ t3 (set → 1) และ t7 (reset → 0)

ข้อ 3 · S′R′ latch แบบ NAND หาค่า Q และ Q′ โจทย์จากสไลด์ 6

เฉลยข้อ 3
  • t0–t2: S′ = 0 ทำให้ set Q = 1 แล้ว hold ต่อ
  • t2: R′ = 0 ทำให้ reset Q = 0, Q′ = 1 แล้ว hold ถึง t4
  • t4: S′ = R′ = 0 ได้ Q = Q′ = 1 (สถานะห้ามใช้ของ NAND)
  • t5: R′ = 1 จึงเหลือ set ได้ Q = 1, Q′ = 0 จากนั้น R′ = 0 อีกครั้ง ได้ Q = Q′ = 1
  • t6: S′, R′ กลับเป็น 1 พร้อมกัน เกิด race จึงเป็น Undefined

ข้อ 4 · SR flip-flop ทริกขอบขาลง (falling-edge) เริ่มต้น Q = 0 โจทย์จากสไลด์ 18

เฉลยข้อ 4 ดูค่า S, R ณ จังหวะขอบขาลง (เส้นประ ↓1–↓4) เท่านั้น
  • ↓1: S = 1, R = 0 ทำให้ Q = 1
  • ↓2: S = R = 0 จึง hold ได้ Q = 1 (พัลส์ S ลูกที่สองเกิดระหว่างขอบ จึงไม่มีผล)
  • ↓3: S = 0, R = 1 ทำให้ Q = 0
  • ↓4: S = R = 0 จึง hold ได้ Q = 0

จุดที่พลาดบ่อย
  • ลืมว่า NAND latch เป็น active-low (ใส่ 0 = สั่งงาน)
  • ตอบค่าสถานะห้ามใช้สลับกัน: NOR ได้ Q, Q′ = 0, 0 ส่วน NAND ได้ 1, 1
  • Latch with Enable ตอน E = 0 ห้ามให้ Q เปลี่ยน แม้ S หรือ R จะเป็น 1
  • Flip-flop ดูค่า S, R เฉพาะ ที่ขอบ ที่ทำงาน ห้ามดูทั้งช่วง (ต่างจาก latch)
  • ปล่อย input ออกจากสถานะห้ามใช้พร้อมกัน ผลคือ Undefined ไม่ใช่ 0 หรือ 1
  • เขียน Qnext = S + R′Q แต่ลืมเงื่อนไข SR = 0
  • ใช้ตารางความจริงแทน excitation table ตอนออกแบบ counter
