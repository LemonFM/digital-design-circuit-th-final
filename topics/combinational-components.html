2รหัส 4 บิต 0–F

Input มี 4 บิต เรียกว่า D C B A โดย D เป็นบิตสูงสุด น้ำหนักบิตคือ 8, 4, 2, 1 จึงมีได้ 2⁴ = 16 ค่า คือ 0 ถึง 15 ค่า 10 ถึง 15 เขียนเป็นเลขฐานสิบหก A ถึง F

ค่า = 8D + 4C + 2B + A

ฐานสิบ101112131415
ฐานสอง DCBA101010111100110111101111
ฐานสิบหกABCDEF
ขึ้นบนจอเป็นAbCdEF
ต่างจาก BCD ในสไลด์อย่างไร BCD (Binary Coded Decimal) ใช้แค่ 0–9 จึงเหลือ 1010 ถึง 1111 เป็น don't care (×) แต่หน้านี้ใช้ครบ 16 ค่า จึงไม่มี × ทุกช่องใน K-map ต้องกำหนดค่า ดูแบบ BCD ได้ในหัวข้อ 8
BCD ไม่เท่ากับเลขฐานสอง เลข 25 ในฐานสองคือ 11001 แต่ใน BCD คือ 0010 0101 เพราะแยกเป็นหลัก 2 กับหลัก 5

3จอ 7-segment

จอมี LED 7 ขีด ชื่อ a ถึง g ไล่ตามเข็มนาฬิกาจากขีดบน และ g คือขีดกลาง ตัวเลขเกิดจากการเลือกว่าขีดไหนติด

ชนิดจอขีดติดเมื่อ
Common cathode (ขั้วลบร่วม)output = 1
Common anode (ขั้วบวกร่วม)output = 0

ตารางในสไลด์ใช้ 1 = ติด จึงตรงกับ common cathode ถ้าเป็น common anode ให้กลับทุกบิตของ output

ตัวอักษรในบทนี้มี 3 ความหมาย D C B A ตัวใหญ่คือ input · a b c d e f g ตัวเล็กคือ ชื่อขีด (output) · ส่วน A, b, C, d, E, F คือรูปที่ขึ้นบนจอ เช่น input D กับขีด d และรูป d เป็นคนละเรื่องกัน สไลด์เรียก input ว่า i3 i2 i1 i0 ซึ่งตรงกับ D C B A ตามลำดับ
ทำไม b กับ d ต้องเป็นตัวเล็ก จอ 7 ขีดวาด B ตัวใหญ่ได้เหมือนเลข 8 และ D ตัวใหญ่ได้เหมือนเลข 0 จึงต้องใช้ b กับ d ตัวเล็กเพื่อให้ทั้ง 16 ค่าไม่ซ้ำกัน
BCD to 7-segment ต่างจาก decoder ทั่วไป decoder ทั่วไปเปิด output ทีละ 1 เส้น แต่วงจรนี้เปิดหลายเส้นพร้อมกัน เช่นเลข 8 เปิดครบ 7 เส้น จึงมองเป็นวงจรแปลงรหัส (code converter) จะตรงกว่า

4ตารางความจริง 0–F

ขั้นแรกของการออกแบบคือเขียนตารางจากรูปบนจอ ถ้าขีดไหนติดให้ใส่ 1 แถว 0–8 ใช้ค่าตามสไลด์ 16 เลข 9 ให้ขีด d ติด และแถว A–F เพิ่มตามรูปในหัวข้อ 2

เลข 6 และ 9 ต่างจากสไลด์บางแผ่น เลข 6 ต้องมีขีดบน (a = 1) เพราะสไลด์ 15 ให้ a = 0 ซึ่งซ้ำกับตัว b พอดี (0011111) ส่วนเลข 9 สไลด์ให้ d = 0 แต่ตารางนี้ให้ d = 1 เพื่อให้เป็นเลข 9 เต็มรูป ทั้ง 16 แถวในตารางนี้ไม่ซ้ำกันเลย

5K-map ทั้ง 7 เส้น

แต่ละขีดเป็น output แยกกัน จึงต้องทำ K-map 7 ตาราง และไม่มีช่อง × เพราะใช้ครบ 16 ค่า สมการจึงยาวกว่าแบบ BCD ในสไลด์

รูปแบบตาราง ใช้แบบเดียวกับบท K-map: แถว BA คอลัมน์ DC ถ้าโจทย์ใช้ตารางแบบอื่น เลขช่องจะอยู่คนละตำแหน่ง แต่สมการที่ได้เหมือนกัน

6สมการทั้ง 7 เส้น

ตารางนี้คือสมการที่ใช้สร้างวงจรในหัวข้อ 7 ขีดที่มีคำตอบน้อยที่สุดหลายแบบ ใช้แบบแรกจาก K-map ในหัวข้อ 5

7วงจรจำลอง 0–F

กดสวิตช์ D C B A หรือกดนับเพิ่มจาก 0 ถึง F แล้วดูสายที่เป็น 1 กับรูปบนจอ ค่าทุกเส้นคำนวณจากเกตที่วาดอยู่ AND ใช้ขนาดเล็กลงเพื่อให้วงจรไม่ยาวเกินไป

8แบบ BCD 0–9

แบบ BCD แสดงแค่ 0–9 ช่อง 10–15 จึงเป็น × ใช้ขยายกลุ่มได้ สมการสั้นกว่าแบบ 0–F มาก ถ้าโจทย์ให้ตารางมา ให้ใช้ค่าตามตารางในโจทย์

เลข 9 ต้องติดขีด d หน้านี้ให้เลข 9 มี d = 1 แต่สไลด์ 15–17 ให้ d = 0 ค่านี้กระทบแค่ขีด d ถ้าใช้ค่าของสไลด์ สมการจะเป็น C′A′ + BA′ + C′B + CB′A ดู K-map ในหัวข้อ 9

10Comparator

Comparator เทียบค่า 2 ค่าแล้วบอกว่าความสัมพันธ์เป็นจริงไหม โดยเลือกเกตตามสิ่งที่ต้องการเทียบ

เทียบเกตหลักสมการ
X = 3AND กลับบิตที่เป็น 0F = x3′x2′x1x0
X ≠ YXOR ทีละบิต แล้ว ORF = Σ (xᵢ ⊕ yᵢ)
X = YXNOR ทีละบิต แล้ว ANDF = Π (xᵢ ⊙ yᵢ)
X < 5เขียนตารางความจริงF = x3′x2′ + x3′x2x1′x0′

สมการ X < 5 ในสไลด์ถูกต้องแต่ยังไม่สั้นสุด ลดได้เป็น x3′x2′ + x3′x1′x0′

Iterative comparator: X = Y

ต่อวงจร 1 บิตเรียงกัน n ตัวแทนการออกแบบวงจรขนาดตายตัว แต่ละตัวส่งต่อ pᵢ ว่าบิตก่อนหน้าเท่ากันหมดไหม

pᵢ₊₁ = pᵢ · (xᵢ ⊙ yᵢ) · เริ่ม p₀ = 1 · ผลคือ p₄

Iterative comparator: X > Y

ส่งต่อ 2 เส้นคือ g (มากกว่า) กับ e (เท่ากัน) เริ่มจากบิตสูงสุด เพราะบิตสูงตัดสินก่อน ค่าเริ่มต้นคือ g = 0, e = 1

12Encoder

Encoder ทำกลับกับ decoder: มี input 2ⁿ เส้น และให้รหัส n บิตของเส้นที่เป็น 1 โดยมีเงื่อนไขว่าเป็น 1 ได้ทีละเส้น เช่น 8-to-3 ที่ I3 = 1 จะได้ 011

Y0 = I1 + I3 + I5 + I7
Y1 = I2 + I3 + I6 + I7
Y2 = I4 + I5 + I6 + I7

หลักจำคือ Yk รวมทุก I ที่เลขของมันมีบิต k เป็น 1 สังเกตว่า I0 ไม่ได้ต่อกับอะไร เพราะรหัสของมันคือ 000

Priority encoder

ถ้า 1 หลายเส้นพร้อมกัน encoder ธรรมดาจะให้รหัสผิด เช่น I1 กับ I4 พร้อมกันได้ 101 ซึ่งเป็นรหัสของ I5 Priority encoder จึงให้เลขสูงสุดชนะ และเพิ่ม Z บอกว่ามี input เป็น 1 หรือไม่ (ถ้าไม่มี Z จะแยก "ไม่มีเส้นไหนเป็น 1" ออกจาก "I0 = 1" ไม่ได้)

วิธีหาสมการในสไลด์ 21 คือสร้างตัวแปรกลาง vk ที่เป็น 1 เมื่อ Ik เป็น 1 สูงสุด คือเส้นเลขสูงกว่าต้องเป็น 0 ทั้งหมด
