1Counter คืออะไร

Counter เป็นวงจร sequential ที่เปลี่ยนค่าตามลำดับทุกครั้งที่มี clock ใช้ flip-flop 1 ตัวเก็บ 1 บิต

คำความหมาย
จำนวนสถานะflip-flop n ตัวมีได้สูงสุด 2ⁿ สถานะ
MOD-Nนับครบ N สถานะแล้ววนกลับ เช่น MOD-10 นับ 0 ถึง 9
หารความถี่บิตสูงสุดของ MOD-N มีความถี่ f/N เมื่อ clock มีความถี่ f
ToggleJ = K = 1 หรือ T = 1 ทำให้ Q กลับค่าทุกขอบ clock
ชนิดClock ของ flip-flopจุดเด่น
Asynchronous (ripple)ตัวแรกรับ clock ตัวถัดไปรับจาก output ตัวก่อนวงจรง่าย แต่ delay สะสม
Synchronousทุกตัวรับ clock เดียวกันเปลี่ยนพร้อมกัน แต่ต้องมีเกตควบคุม
Decade, Up/Downขึ้นกับการออกแบบนับ 0–9 หรือเลือกนับขึ้นลงได้

2Asynchronous counter

ทุกตัวต่อ J = K = 1 จึง toggle ทุกครั้งที่ขา clock ของตัวเองได้รับขอบ ตัวแรกรับ CLK ส่วนตัวถัดไปใช้ output ของตัวก่อนเป็น clock สัญญาณจึงไล่เป็นทอด ๆ จนเรียกว่า ripple counter

QA เปลี่ยนทุกขอบขาลงของ CLK จึงได้ f/2 · QB เปลี่ยนทุกขอบขาลงของ QA จึงได้ f/4 · QC ได้ f/8

นับขึ้นหรือนับลงดูจาก 2 อย่าง ชนิดขอบของ flip-flop กับสายที่ต่อเข้า clock ตัวถัดไป
ขอบ clockต่อจากทิศการนับ
ขาลง (มีวงกลม)Qนับขึ้น
ขาลง (มีวงกลม)Q′นับลง
ขาขึ้น (ไม่มีวงกลม)Qนับลง
ขาขึ้น (ไม่มีวงกลม)Q′นับขึ้น
รูปในสไลด์ 5 ขัดกับ timing วงจรวาดขา CLK แบบขอบขาขึ้น แต่ timing เปลี่ยนที่ขอบขาลง ถ้าเป็นขอบขาขึ้นจริงและต่อจาก Q จะนับลง หน้านี้จึงวาดเป็นขอบขาลงให้ตรงกับ timing

3Clock ripple

flip-flop แต่ละตัวมี propagation delay (tpd) ตัวถัดไปจึงเปลี่ยนช้ากว่าตัวก่อน delay นี้สะสมตามจำนวนบิต เรียกว่า clock ripple

delay ของบิตสุดท้าย = n × tpd

ตัวอย่างในสไลด์ 7 คือจังหวะนับจาก 7 ไป 8 ซึ่งต้องเปลี่ยนทุกบิต output จึงผ่านค่าชั่วคราวก่อนถึงค่าจริง

จังหวะQ3 Q2 Q1 Q0ค่าที่อ่านได้เกิดอะไร
ก่อนขอบ0 1 1 17ค่าเดิม
หลัง 1 tpd0 1 1 06Q0 เปลี่ยนจาก 1 เป็น 0
หลัง 2 tpd0 1 0 04Q1 ตามมา
หลัง 3 tpd0 0 0 00Q2 ตามมา
หลัง 4 tpd1 0 0 08Q3 เปลี่ยน ได้ค่าจริง
ทำไมถึงเป็นปัญหา ค่า 6, 4, 0 ไม่ใช่ค่าที่ต้องการ แต่เกิดขึ้นจริงชั่วขณะ ถ้าวงจรอื่นอ่านช่วงนี้จะได้ค่าผิด และ clock ต้องไม่เร็วเกินเวลาที่ทุกบิตนิ่ง เช่น 4 บิต tpd = 25 ns ต้องรอ 100 ns จึงใช้ clock ได้ไม่เกิน 10 MHz

4MOD-N counter

ripple counter n บิตนับครบ 2ⁿ ถ้าต้องการนับแค่ N สถานะให้ ตรวจจับค่า N แล้ว reset ทุกตัวทันที

  1. หาจำนวน flip-flop ที่ 2ⁿ ≥ N
  2. เขียน N เป็นเลขฐานสอง
  3. นำบิตที่เป็น 1 เข้าเกต: AND ถ้า reset เป็น active-high หรือ NAND ถ้าเป็น active-low
  4. ต่อ output ของเกตเข้าขา reset ของทุกตัว

MOD-5 (สไลด์ 8)

5 = 101 จึงใช้ AND ของ QC กับ QA วงจรนี้ใช้ D flip-flop ขอบขาขึ้น ต่อ D = Q′ ให้ toggle และต่อ Q′ เข้า clock ตัวถัดไปจึงนับขึ้น

MOD-10 (สไลด์ 9)

10 = 1010 จึงใช้ NAND ของ QD กับ QB ต่อเข้า Clr′ ซึ่งเป็น active-low ใช้ JK ขอบขาลง (74LS73) กับ NAND (74LS00)

ค่า N ปรากฏชั่วขณะ วงจรต้องแตะค่า N ก่อนจึงจะ reset ได้ MOD-5 จึงเป็น 101 สั้น ๆ ก่อนกลับ 000 เป็น glitch ลำดับที่อ่านได้จริงคือ 0, 1, 2, 3, 4 แล้ววนกลับ
ทำไมใช้แค่บิตที่เป็น 1 ตอนนับขึ้น ครั้งแรกที่บิตเหล่านี้เป็น 1 พร้อมกันคือค่า N พอดี จึงไม่ต้องตรวจบิตที่เป็น 0

6Synchronous counter

ทุก flip-flop รับ clock เดียวกันจึงเปลี่ยนพร้อมกัน ส่วนเกตควบคุมจะกำหนดว่าขอบนี้บิตไหนต้อง toggle กฎคือ บิตหนึ่ง toggle เมื่อบิตที่ต่ำกว่าทุกตัวเป็น 1

"ไม่มี propagation delay" ไม่ได้แปลว่าไม่มีเลย flip-flop ยังมี tpd อยู่ แต่ทุกบิตเปลี่ยนในเวลาเดียวกัน delay จึงไม่สะสม และไม่เกิดค่าชั่วคราวแบบ ripple

7Synchronous MOD-10

วงจรสไลด์ 15 ไม่ใช้ reset แต่ใช้เกตบังคับให้จาก 9 กลับ 0 ที่ขอบ clock โดยตรง จึงไม่มี glitch แบบ MOD-N ในหัวข้อ 4 ถ้าเริ่มที่รหัส 10–15 ก็กลับเข้าวง 0–9 เองภายใน 2 clock

10Count down

นับลงคือค่าลดลงทีละขั้น หรือย้อนลำดับที่ออกแบบไว้ หัวข้อนี้เริ่มจากตัวนับเลขเรียงก่อน แล้วค่อยเป็นลำดับเลขโดดของสไลด์

Next state นับลงเลขเรียง 3 บิต

นับถึง 000 แล้ววนกลับไป 111 ค่าถัดไปจึงเป็นค่าปัจจุบันลบ 1

Asynchronous นับลง

ใช้ flip-flop ขอบขาลงเหมือนเดิม แต่ต่อ Q′ เข้า clock ตัวถัดไปแทน Q บิตถัดไปจึงเปลี่ยนเมื่อบิตนี้เปลี่ยนจาก 0 เป็น 1

ทุกตัวใช้ clock เดียวกัน กฎกลับกับนับขึ้นคือ บิตหนึ่ง toggle เมื่อบิตที่ต่ำกว่าทุกตัวเป็น 0

11Up/Down counter

เพิ่ม input sw เพื่อเลือกทิศ sw = 1 นับขึ้น และ sw = 0 นับลง วิธีตามสไลด์ 32 คือรวมสมการทั้งสองชุด

  1. นำสมการนับขึ้นทุกเส้น AND กับ sw
  2. นำสมการนับลงทุกเส้น AND กับ sw′
  3. OR ทั้งสองส่วน ได้สมการใหม่สำหรับวาดวงจร

สมการรวม = sw · (นับขึ้น) + sw′ · (นับลง)

สไลด์ 33–34 เว้นว่างไว้ ตารางนี้จึงทำให้ครบจากสมการ JK ของหัวข้อ 9 และ 10

แบบนับเลขฐานสอง 3 บิต

หลักการเดียวกันใช้กับ binary ได้ นับขึ้น toggle เมื่อบิตต่ำเป็น 1 หมด ส่วนนับลง toggle เมื่อบิตต่ำเป็น 0 หมด

TA = 1 · TB = sw·A + sw′·A′ · TC = sw·BA + sw′·B′A′

13การใช้งาน

  • นาฬิกาดิจิทัล: นับเวลาโดยเพิ่มค่าเป็นช่วงคงที่
  • Frequency counter: นับจำนวน pulse ในช่วงเวลาที่กำหนดเพื่อวัดความถี่
  • ตัวหารความถี่: ใช้บิตสูงสุดของ MOD-N ลดความถี่เป็น f/N
  • ไฟจราจรและระบบควบคุม: ใช้นับจังหวะการทำงานตามลำดับ
  • Up/Down counter: ใช้ใน digital-to-analog converter และระบบควบคุมดิจิทัล
