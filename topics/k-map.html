Karnaugh Map (K-map)

K-map คือตารางที่ช่วยลดรูปสมการลอจิกด้วยการจับกลุ่มช่องที่อยู่ติดกัน หน้านี้ใช้ตัวแปร DCBA โดยแถวคือ BA และคอลัมน์คือ DC ตั้งแต่ 2 ถึง 4 ตัวแปร (ใหญ่สุด 4 × 4)

สารบัญ
  1. K-map คืออะไร
  2. รูปแบบตาราง DCBA
  3. กฎการจับกลุ่ม
  4. อ่านสมการจากกลุ่ม
  5. Prime implicant (PI)
  6. ตัวอย่างทีละขั้น
  7. Don't care (×)
  8. รูป POS (จับกลุ่ม 0)
  9. ลองกด K-map
  10. แบบฝึก
  11. สรุปก่อนสอบ

1K-map คืออะไร

K-map คือ truth table ที่จัดเรียงใหม่ให้ช่องที่อยู่ติดกันต่างกันแค่ 1 บิต จึงมองเห็นคู่ที่ยุบรวมกันได้ทันที ตามกฎ XA + XA′ = X

ตัวอย่างการยุบ ช่อง D′C′B′A กับ D′C′BA ต่างกันแค่ B: D′C′B′A + D′C′BA = D′C′A(B′ + B) = D′C′A ตัวแปรที่เปลี่ยนค่าจะหายไป

ผลลัพธ์คือสมการที่ใช้เกตน้อยลง ซึ่งเป็นขั้นที่ใช้ตอนแปลง flip-flop และออกแบบวงจร

2รูปแบบตาราง DCBA

ตัวแปรเรียงเป็น D C B A โดย D เป็นบิตสูงสุด เลขในช่องคือ minterm: เลขช่อง = 8D + 4C + 2B + A

หัวตารางเรียง 00, 01, 11, 10 ไม่ใช่ 00, 01, 10, 11 ลำดับนี้คือ Gray code เปลี่ยนทีละ 1 บิต เลขช่องจึงไม่เรียงกัน: แถว BA = 00 คือ 0, 4, 12, 8 และแถว BA = 10 อยู่ล่างสุดคือ 2, 6, 14, 10
ขนาดตัวแปรแถวคอลัมน์จำนวนช่อง
2 × 2B AAB4
4 × 2C B AB AC8
4 × 4D C B AB AD C16

ถ้าโจทย์ใช้ตารางคนละแบบ เช่นเรียงเป็น ABCD เลขช่องจะไม่ตรงกับหน้านี้ ให้ดูหัวตารางของโจทย์ก่อนเสมอ

3กฎการจับกลุ่ม

  1. จับเฉพาะ 1 (รูป SOP) ห้ามมี 0 ในกลุ่ม
  2. ขนาดกลุ่มต้องเป็น 1, 2, 4, 8 หรือ 16 ช่องเท่านั้น
  3. กลุ่มต้องเป็นสี่เหลี่ยมผืนผ้า ห้ามทแยงมุม ห้ามเป็นรูปตัว L
  4. ทำกลุ่มให้ใหญ่ที่สุด กลุ่มใหญ่ได้ตัวแปรน้อยกว่า
  5. ใช้จำนวนกลุ่มน้อยที่สุด ที่ครอบ 1 ได้ครบ (ดูวิธีเลือกในหัวข้อ 5)
  6. กลุ่มซ้อนกันได้ ช่องเดียวอยู่ได้หลายกลุ่ม
  7. ขอบตารางต่อกัน: ซ้ายต่อขวา บนต่อล่าง และ 4 มุมเป็นกลุ่มเดียวกันได้

4อ่านสมการจากกลุ่ม

ดูทีละตัวแปรในกลุ่ม: ตัวแปรที่เปลี่ยนค่าตัดทิ้ง ตัวแปรที่คงที่ให้เก็บไว้ ถ้าคงที่เป็น 1 เขียนตัวแปรปกติ ถ้าคงที่เป็น 0 เขียนนิเสธ (′)

ขนาดกลุ่มตัดตัวแปรเหลือ (K-map 4 ตัวแปร)
1 ช่อง0 ตัว4 ตัวแปร
2 ช่อง1 ตัว3 ตัวแปร
4 ช่อง2 ตัว2 ตัวแปร
8 ช่อง3 ตัว1 ตัวแปร
16 ช่อง4 ตัวเหลือ F = 1
ตัวอย่าง: กลุ่ม 0, 1, 8, 9 เลขฐานสอง DCBA คือ 0000, 0001, 1000, 1001 · D เปลี่ยน ตัดทิ้ง · C = 0 คงที่ ได้ C′ · B = 0 คงที่ ได้ B′ · A เปลี่ยน ตัดทิ้ง · จึงได้ C′B′

5Prime implicant (PI)

การจับกลุ่มให้ถูกวิธีคือหา PI ทั้งหมดก่อน แล้วค่อยเลือกชุดที่น้อยที่สุด คำศัพท์ที่ต้องรู้มี 4 คำ

คำความหมายต้องใส่ในคำตอบไหม
Implicantกลุ่ม 1, 2, 4, 8 หรือ 16 ช่องที่ไม่มี 0 จะเล็กแค่ไหนก็ได้ไม่จำเป็น
Prime implicant (PI)Implicant ที่ขยายให้ใหญ่ขึ้นอีกไม่ได้ เพราะถ้าขยายจะไปโดน 0เลือกจากชุดนี้เท่านั้น
Essential PI (EPI)PI ที่เป็นตัวเดียวที่ครอบ 1 ช่องใดช่องหนึ่งต้องใส่เสมอ
Non-essential PIPI ที่ทุกช่อง 1 ของมันมี PI อื่นครอบได้ด้วยใส่เท่าที่จำเป็น

ขั้นตอน

  1. หา PI ทั้งหมด (prime implicant set): ไล่ทีละช่อง 1 แล้วขยายกลุ่มจนขยายต่อไม่ได้
  2. หา EPI: ดูแต่ละช่อง 1 ถ้ามี PI ครอบตัวเดียว PI นั้นคือ EPI
  3. ใส่ EPI ทุกตัว แล้วขีดช่อง 1 ที่ครอบแล้วออก
  4. เลือก PI ที่เหลือให้น้อยที่สุดเพื่อครอบ 1 ที่ยังเหลือ

หาคำตอบด้วย power set ของ PI

Power set คือเซตของสับเซตทั้งหมด ถ้ามี PI n ตัว จะมี 2n สับเซต แต่ละสับเซตคือคำตอบที่เป็นไปได้ 1 แบบ เพราะคำตอบที่น้อยที่สุดต้องประกอบจาก PI เท่านั้น จึงไล่ได้ดังนี้

  1. เขียนสับเซตของ PI ทุกแบบ รวมเซตว่าง
  2. เช็กว่าแต่ละสับเซตครอบ 1 ครบทุกช่องไหม (ช่อง × ไม่ต้องครอบ)
  3. จากชุดที่ครบ เลือกเทอมน้อยที่สุด ถ้าเท่ากันเลือกตัวแปรน้อยที่สุด
จำนวน PIจำนวนสับเซตถ้าล็อก EPI ไว้ 2 ตัว
32³ = 82¹ = 2
42⁴ = 162² = 4
62⁶ = 642⁴ = 16
EPI ช่วยลดงาน วิธีนี้ไล่ครบทุกแบบจึงไม่พลาดคำตอบ แต่จำนวนสับเซตเพิ่มเท่าตัวทุกครั้งที่มี PI เพิ่ม 1 ตัว EPI ต้องอยู่ในคำตอบเสมอ จึงล็อกไว้แล้วหา power set เฉพาะ PI ที่เหลือก็พอ
อ่านตาราง PI แถวคือ PI คอลัมน์คือช่อง 1 · ● คือ PI นั้นครอบช่องนั้น · ◉ คือมี PI นี้ครอบตัวเดียว จึงเป็น EPI · แถวที่ระบายคือ EPI · ช่อง × ไม่ต้องอยู่ในตาราง เพราะไม่ต้องครอบให้ครบ แต่ PI ใช้ × ขยายกลุ่มได้

6ตัวอย่างทีละขั้น

7Don't care (×)

× คือช่องที่ไม่สนใจค่า เพราะ input แบบนั้นไม่เกิดขึ้นหรือ output เป็นอะไรก็ได้ เลือกนับ × เป็น 1 ได้เมื่อทำให้กลุ่มใหญ่ขึ้น แต่ไม่ต้องครอบ × ทุกช่อง และไม่ต้องสร้างกลุ่มเพื่อครอบ × อย่างเดียว

ใช้ × ช่อง 5 เป็น 1 กลุ่ม 1, 3, 5, 7 จึงเป็น 4 ช่อง สมการสั้นลง ส่วน × ช่อง 0 ไม่ได้ใช้ ปล่อยไว้ได้ · ตาราง excitation ของ JK และ SR ในหน้าสรุปใช้ × แบบเดียวกันนี้

8รูป POS (จับกลุ่ม 0)

ถ้าต้องการรูปผลคูณของผลบวก (Product of Sums) ให้จับกลุ่ม 0 แล้วอ่านกลับด้าน: ตัวแปรคงที่เป็น 0 เขียนตัวแปรปกติ คงที่เป็น 1 เขียนนิเสธ และแต่ละกลุ่มเป็นวงเล็บบวก

ที่มาของการอ่านกลับด้าน กลุ่ม 0 ให้สมการของ F′ แบบ SOP แล้วใช้ De Morgan: เทอม DC ใน F′ กลายเป็น (D′ + C′) ใน F
