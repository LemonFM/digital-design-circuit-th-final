1Synchronous vs Asynchronous

Synchronous inputs

D, J, K, T, S, R จะมีผล เฉพาะที่ขอบ clock เท่านั้น

Asynchronous inputs

PreN, ClrN (หรือ Set′, Clear′) มีผล ทันที ไม่ต้องรอ clock และ มีสิทธิ์เหนือกว่า input แบบ synchronous

ชิปจริงให้ Q = Q′ = 1 และไม่คงที่เมื่อปล่อย

ตัว N และวงกลมแปลว่า active-low PreN และ ClrN ลงท้ายด้วย N (Negative) และในสัญลักษณ์มีวงกลมที่ขา แปลว่า ใส่ 0 เพื่อสั่งงาน ตอนใช้งานปกติต้องตั้งไว้ที่ 1

3วงจรระดับเกต สไลด์ 28 (a)

เอา D latch with Enable มาเพิ่ม input ตัวที่ 3 ให้ NAND ทั้งสองตัวของ latch

  • Set′ = 0: NAND ตัวบนได้ input เป็น 0 จึงได้ Q = 1 ทันที ไม่ว่า E, D จะเป็นอะไร
  • Clear′ = 0: NAND ตัวล่างได้ Q′ = 1 จึงได้ Q = 0 ทันที
  • เพราะต่อตรงเข้า latch โดยไม่ผ่านเกตของ E จึงเป็น asynchronous
หมายเหตุ ตรวจทานเพิ่ม รูปในสไลด์ 28 (a) เป็น latch ที่มี Set′/Clear′ ถ้าเป็น flip-flop แบบ master–slave ต้องต่อ Set′/Clear′ เข้า ทั้ง master และ slave ไม่เช่นนั้นพอ clock เปลี่ยน slave อาจคัดลอกค่าเก่าจาก master มาทับ

4ลองกดวงจร

D flip-flop ขอบขาขึ้นที่มี PreN, ClrN ลองตั้ง ClrN = 0 แล้วส่ง clock พร้อม D = 1 จะเห็นว่า Q ยังเป็น 0 เพราะ Clear มีสิทธิ์เหนือกว่า

เฉลยข้อ 1
  • ต้น ~ t1: ClrN = 0 จึงได้ Q = 0 (ที่ t1 ถึง D = 1 ก็ไม่มีผล เพราะ Clear ยังทำงานอยู่)
  • t2: ClrN = PreN = 1 และ D = 1 จึงได้ Q = 1
  • t3: D = 0 จึงได้ Q = 0
  • ระหว่าง t3–t4: PreN = 0 จึงได้ Q = 1 ทันที ไม่รอขอบ
  • t4: D = 0 จึงได้ Q = 0

เฉลยข้อ 2
  • PreN = 0 ตั้งแต่ช่วงต้น จึงได้ Q = 1 ทันที (↓1 อยู่ในช่วง Preset จึงไม่มีผล)
  • ↓2: JK = 01 จึง Reset ได้ Q = 0
  • ↓3: JK = 10 จึง Set ได้ Q = 1
  • ClrN = 0 จึงได้ Q = 0 ทันที (↓4 อยู่ในช่วง Clear จึงไม่มีผล)
  • ↓5: JK = 11 จึง Toggle จาก 0 เป็น 1

6สรุปก่อนสอบ

PreNClrNผล
00ห้ามใช้
01Q = 1 ทันที (ไม่สน clock)
10Q = 0 ทันที (ไม่สน clock)
11ทำงานปกติตามขอบ clock
จุดที่พลาดบ่อย
  • รอให้ถึงขอบ clock ก่อนค่อยเปลี่ยน Q ตอน PreN/ClrN = 0 (ที่ถูกคือเปลี่ยนทันที)
  • ลืมว่าเป็น active-low: ใส่ 1 คือปิดการทำงาน ส่วน 0 คือสั่งงาน
  • ใช้ D/JK ที่ขอบ clock ทั้งที่ ClrN หรือ PreN ยังเป็น 0 อยู่
  • พอ PreN/ClrN กลับเป็น 1 แล้ว Q ไม่เด้งกลับ แต่ค้างค่าไว้จนถึงขอบ clock ถัดไป
