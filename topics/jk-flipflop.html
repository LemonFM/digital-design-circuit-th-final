JK Flip-Flop

4Timing และ propagation delay สไลด์ 21

Figure 11-20 เป็น JK ที่ Q เปลี่ยนที่ขอบขาขึ้น และในรูปจะเห็นว่า Q เปลี่ยนหลังขอบเล็กน้อย ระยะนี้คือ tp (propagation delay) ซึ่งเป็นเวลาที่วงจรใช้ในการตอบสนอง

  • ดูค่า J, K ก่อนขอบนิดเดียว แล้วตัดสินว่า Q จะเป็นอะไร
  • Q จะเปลี่ยนหลังขอบไป tp ถ้าโจทย์ไม่ได้ให้ tp มา ให้วาดเปลี่ยนตรงขอบได้เลย

5Master–Slave JK flip-flop สไลด์ 22

โครงเหมือน master–slave SR แต่ ป้อน Q และ Q′ กลับมา AND กับ J, K ก่อนเข้า master (Figure 11-21)

  • ถ้า Q = 0 จะมีแค่ J ที่ผ่าน (J·Q′) จึงทำได้แค่ Set · ถ้า Q = 1 จะมีแค่ K ที่ผ่าน (K·Q) จึงทำได้แค่ Reset
  • เมื่อ J = K = 1 ฝั่งที่ผ่านคือฝั่งที่ทำให้ Q กลับค่าพอดี จึงได้ toggle และ S₁, R₁ ไม่มีทางเป็น 1 พร้อมกัน
  • master รับค่าตอน CLK = 0 แล้ว slave ส่งออกตอน CLK ขึ้น จึงได้ Q เปลี่ยนที่ ขอบขาขึ้น
Ones catching: ข้อเสียของ master–slave JK ตรวจทานเพิ่ม master เปิดรับ input ตลอดช่วง CLK = 0 ถ้า Q = 0 แล้ว J เด้งเป็น 1 แป๊บเดียว master จะถูก set และกลับไม่ได้ (เพราะ K·Q = 0) พอถึงขอบ Q ก็กลายเป็น 1 ทั้งที่ ณ ขอบ J = 0 จึงเรียก master–slave JK ว่า pulse-triggered ส่วน JK แบบ edge-triggered แท้จะดูค่า J, K เฉพาะ ณ ขอบ (โจทย์ timing ในหน้านี้ถือเป็นแบบ edge-triggered)
ทำไม JK ต้องเป็น edge-triggered เสริม ไม่มีในสไลด์ ถ้าเป็น latch แบบ level-triggered แล้ว J = K = 1 ตลอดช่วง clock = 1 Q จะ toggle วนไปเรื่อย ๆ จนผลบอกไม่ได้ (race-around) การใช้ขอบหรือ master–slave ทำให้ toggle ได้แค่ครั้งเดียวต่อ 1 ลูก clock

6ลองกดวงจร

ตั้ง J, K แล้วกด "ส่ง clock 1 ลูก" ลองตั้ง J = K = 1 แล้วกดหลาย ๆ ครั้ง จะเห็น Q สลับทุกลูก

วิธีคิด

  • 0 → 0: JK = 00 หรือ 01 จึงได้ J = 0, K = ×
  • 0 → 1: JK = 10 หรือ 11 จึงได้ J = 1, K = ×
  • 1 → 0: JK = 01 หรือ 11 จึงได้ J = ×, K = 1
  • 1 → 1: JK = 00 หรือ 10 จึงได้ J = ×, K = 0

เทคนิค: ถ้า Q = 0 ตอนนี้ K เป็น × เสมอ ถ้า Q = 1 J เป็น × เสมอ
