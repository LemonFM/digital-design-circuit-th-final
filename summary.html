  1. เขียนตารางของตัวที่ อยากได้ (input ของมัน + Q → Qnext)
  2. ใช้ excitation table ของตัวที่มีอยู่ หาค่า input ที่ทำให้ได้ Qnext นั้น (ถ้าใช้ D คือ D = Qnext)

9วิธีทำโจทย์ timing diagram

  1. ดูว่าเป็น latch (ตามระดับ) หรือ flip-flop (ตามขอบ) และถ้าเป็น flip-flop ให้ดูว่าใช้ ขอบขาขึ้นหรือขาลง
  2. ลากเส้นแนวตั้งที่ขอบที่ทำงานทุกขอบ (สำหรับ latch ให้แรเงาช่วงที่ enable = 1)
  3. ไล่ดู PreN / ClrN ก่อน ช่วงไหนเป็น 0 ให้ Q ตามนั้นทันที
  4. ที่แต่ละขอบ ให้อ่าน input ณ ขอบนั้น (ค่าก่อนขอบนิดเดียว) แล้วเปิดตารางของ flip-flop ชนิดนั้น
  5. Toggle ให้กลับค่าจาก Q ก่อนขอบ · Hold ให้ใช้ค่าเดิม
  6. ระหว่างขอบ Q คงที่ (ยกเว้น latch ช่วง enable และ Preset/Clear)

10จุดที่พลาดบ่อย

  • สลับสถานะห้ามใช้: NOR ได้ 0, 0 ส่วน NAND ได้ 1, 1
  • ลืมว่า NAND latch, PreN, ClrN เป็น active-low
  • อ่าน input ตลอดช่วงแทนที่จะอ่าน ณ ขอบ (flip-flop) หรือกลับกัน (latch)
  • ตอบ JK = 11 ว่าห้ามใช้ (ที่ถูกคือ Toggle)
  • T = 1 คือกลับค่าจาก Q เดิม ไม่ใช่ Q = 1
  • เขียน Qnext = S + R′Q โดยไม่ใส่เงื่อนไข SR = 0
  • สลับตำแหน่ง × ใน excitation table ของ JK
  • PreN/ClrN กลับเป็น 1 แล้ว Q ไม่เด้งกลับ แต่ค้างไว้จนถึงขอบถัดไป
  • master–slave SR/JK เป็น pulse-triggered (ones catching) แต่ master–slave D เป็น edge-triggered แท้

11พื้นฐานก่อนเรียน PIPO

PIPO ประกอบจาก D flip-flop กับ MUX ถ้าเข้าใจ 4 เรื่องนี้จะอ่านวงจรได้ทันที

1. D flip-flop

CkDQQ⁺
↑000
↑010
↑101
↑111
0, 1, ↓×00 (คงเดิม)
0, 1, ↓×11 (คงเดิม)

จำแค่นี้

  • Q⁺ = D ที่ขอบ clock
  • D เปลี่ยนระหว่างขอบไม่มีผล
  • 1 ตัวเก็บ 1 บิต
  • ไม่มีสถานะห้ามใช้

2. MUX 4-to-1

MUX คือสวิตช์เลือกสัญญาณ: select 2 ขา เลือกได้ 4 ช่อง ส่งค่าช่องนั้นออกไป ค่า select อ่านเป็นเลข 0–3 ก็คือหมายเลขช่อง

SHSel₁SHSel₀SHSelออกจากช่อง
000ช่อง 0
011ช่อง 1
102ช่อง 2
113ช่อง 3

วิธีแปลงเป็นเลข

SHSel = 2·SHSel₁ + SHSel₀

SHSel₁ เป็นบิตหลักสอง เช่น SHSel₁ = 1, SHSel₀ = 0 คือ SHSel = 2 ไม่ใช่ 1

3. การคงค่า

D flip-flop รับค่าขา D ทุกขอบเสมอ จะให้คงค่าเดิมต้องป้อน Q ของตัวเองกลับเข้า D จึงได้ Q⁺ = Q ไม่ใช่การหยุด clock (หยุด clock ด้วยเกตเสี่ยง glitch และ clock skew)

4. Register และการเปลี่ยนค่าพร้อมกัน

  • Register n บิต คือ D flip-flop n ตัวที่ใช้ clock เส้นเดียวกัน
  • ทุกตัวอ่านค่าก่อนขอบ แล้วเปลี่ยนพร้อมกัน จึงเลื่อนได้ทีละหนึ่งช่อง ไม่ทะลุทั้งแถว
  • ในหน้านี้ Q3 อยู่ซ้ายสุด Q0 อยู่ขวาสุด เลื่อนขวา คือข้อมูลไหลจาก Q3 ไป Q0

12PIPO คืออะไร อ่านเพิ่ม

Parallel-in, Parallel-out: ข้อมูลเข้าพร้อมกันทุกบิต และออกพร้อมกันทุกบิต จึงโหลด 4 บิตได้ใน clock ลูกเดียว และอ่าน Q3–Q0 ได้ตลอดเวลา

ชนิดข้อมูลเข้าข้อมูลออกใส่ 4 บิตใช้ clockอ่านครบใช้ clock เพิ่ม

ทำไมต้องมี MUX ถ้าต่อ D ตรงเข้า flip-flop ทุกขอบจะโหลดค่าใหม่ เก็บค่าไว้ไม่ได้ จึงใส่ MUX หน้าขา D ทุกบิตเพื่อเลือกว่าขอบนี้จะคงค่า โหลด เลื่อน หรือหมุน

4 โหมดนี้จำจากสิ่งที่ต่อเข้าช่อง
  • คงค่า: ทุกบิตรับ Q ตัวเอง
  • Parallel load: ทุกบิตรับ D ของตัวเอง

  • Rotate right: ทุกบิตรับบิตทางซ้าย Q3 รับ Q0 ข้อมูลไม่หาย หมุน 4 ครั้งกลับค่าเดิม

14วิธีทำข้อสอบ PIPO ฝึกในแนวข้อสอบ

โจทย์อาจสลับช่องของ MUX จึงอย่าท่องรหัส ให้อ่านจากรูปทุกครั้งตาม 3 ขั้นนี้

  1. อ่านวงจร: ดู MUX ของ Q3 ว่าแต่ละช่องต่อกับอะไร แล้วบอกโหมดของช่องนั้น
    • ต่อ Q3 ตัวเอง = คงค่า · ต่อ D3 = โหลด · ต่อ Serial_in = Shift right · ต่อ Q0 = Rotate right
  2. เขียนตาราง control: แถว SHSel₁ SHSel₀ แต่ละแถว เติม Q3⁺ Q2⁺ Q1⁺ Q0⁺ ตามโหมด
  3. ไล่ทีละขั้น: อ่าน SHSel ของแถวนั้น เปิดตาราง control แล้วแทนค่าด้วย Q ก่อนขอบ, D และ Serial_in

ตัวอย่าง: วงจรที่สลับช่อง

ขั้น 1: MUX ของ Q3: ช่อง 0 ต่อ Q0 (Rotate), ช่อง 1 ต่อ D3 (Load), ช่อง 2 ต่อ Q3 (คงค่า), ช่อง 3 ต่อ Serial_in (Shift right)

15จุดที่พลาดบ่อยของ PIPO

  • ใช้รหัสตามสไลด์ 14 ทันทีโดยไม่ดูรูป (ต้องดูว่าช่องไหนต่อกับอะไร)
  • แปลง SHSel₁ SHSel₀ สลับหลัก: 1 0 คือ 2 ไม่ใช่ 1
  • ใช้ค่าใหม่ของบิตข้าง ๆ ในขอบเดียวกัน (ที่ถูกคือใช้ค่าก่อนขอบทุกบิต)
  • Rotate แล้วใส่ Serial_in เข้า Q3 (ที่ถูกคือ Q0 เดิม)
  • คิดว่า Q เปลี่ยนตามทันทีตอน SHSel หรือ D เปลี่ยน (ที่ถูกคือเปลี่ยนเฉพาะที่ขอบ clock)
  • สับสนทิศ: เลื่อนขวาคือข้อมูลไหลจาก Q3 ไป Q0 และบิตที่หลุดออกคือ Q0
