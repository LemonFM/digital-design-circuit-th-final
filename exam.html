แนวข้อสอบ

เลือก ปรนัย หรือ อัตนัย แล้วเลือกเรื่องที่จะซ้อม ปรนัยจะตรวจทันทีที่ตอบ ส่วนอัตนัยให้ลองทำในกระดาษก่อนแล้วค่อยกดดูเฉลย

แนวที่ได้มา
  • SR flip-flop
  • D FF
  • D FF → JK FF
  • Input synchronous

"D FF → JK FF" ปกติหมายถึงใช้ D FF สร้าง JK (D = JQ′ + K′Q) แต่เผื่อไว้ว่าอาจหมายถึงทิศกลับ จึงมีแท็บ "JK FF → D FF" (J = D, K = D′) ให้ด้วย · "Input synchronous" ตีความว่าเป็นเรื่อง synchronous input (มีผลที่ขอบ clock) เทียบกับ asynchronous input (Preset/Clear) รวมถึง synchronous reset/enable · โจทย์ทั้งหมดแต่งขึ้นเองเพื่อซ้อม ไม่ใช่ข้อสอบจริง
